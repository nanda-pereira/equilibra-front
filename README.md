# Equilibra - Front-end
aplicação web do Equilibra, uma plataforma de apoio ao acompanhamento e ao cuidado de pessoas com doença de Parkinson.

## | tecnologias
React · Vite · TypeScript · Tailwind CSS v4 · React Router

## | como executar
**pré-requisito:** Node.js e npm instalados.

```bash
git clone <URL_DO_REPOSITORIO>
cd equilibra-front
npm install
npm run dev
```

após iniciar o servidor, acesse o endereço local exibido no terminal.
